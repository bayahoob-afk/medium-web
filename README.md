# 🔮 Medium — ดูดวงสดกับหมอดูตัวจริง + หมอดู AI

เว็บแอปสาธิตของแพลตฟอร์ม **Medium** ตัวกลางระหว่างหมอดูกับลูกดวง

🌐 **เว็บไซต์:** https://bayahoob-afk.github.io/medium-web/

## จุดเด่น

- 🎥 ทุกเซสชันดูดวงมีการอัดวิดีโอ (ขอความยินยอมทั้งสองฝ่ายก่อนเริ่ม) พร้อมเล่นย้อนหลัง/ดาวน์โหลด
- 📋 สรุปคำทำนายส่งให้หลังจบเซสชันทันที
- 🕯️ **หมอดู AI** — ศึกษาศาสตร์ความเชื่อจริง 4 องค์: พระตรีมูรติ (ความรัก — ละเอียดที่สุด), พระพิฆเนศ, พระแม่ลักษมี, พระราหู
- 📱 PWA ติดตั้งเป็นแอปได้ทั้ง Android/iOS

## โครงสร้าง

เว็บ static ล้วน (HTML/CSS/JS ไม่มี build step) — เปิด `index.html` หรือรัน `python3 -m http.server` ก็ใช้ได้ทันที
Deploy อัตโนมัติขึ้น GitHub Pages ผ่าน `.github/workflows/deploy.yml` ทุกครั้งที่ push ไป `main`

## ข้อจำกัดความรับผิดชอบ

บริการนี้เพื่อความบันเทิง เป็นแนวทางและกำลังใจเท่านั้น ไม่ใช่คำแนะนำทางการแพทย์ การเงิน หรือกฎหมาย
